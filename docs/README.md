## 自己 PR

**決済システムの設計から移行まで一貫して担えるエンジニア**

DeNA・STORES の 2 社で 4 年間、決済領域を中心にフルスタックエンジニアとしてキャリアを積んできました。DeNA では Amazon Pay・Apple Pay・Google Pay の 3 つの決済手段を導入し、STORES では GMV 10 数億円規模のサービスにおける Stripe から GMO への決済移行を無停止で完遂、年間数千万円規模のコスト削減に貢献しました。

決済の導入だけでなく、加盟店審査・入金を含む決済基盤全体の設計・移行経験があり、3D Secure 認証のフルスタック実装やデータ移行におけるデータ整合性の担保など、決済ドメイン特有の技術的課題にも対応できます。今後はこの専門性を軸に、より大規模な決済基盤の構築や技術的意思決定に携わっていきたいと考えています。

- **GMV 10 数億円規模のサービスにおける決済手数料の削減と安定性の向上**

**担当業務**

- Stripe から GMO へのデータ移行処理の実装とデータ整合性の担保

**成果**

- 決済・審査・入金の全領域の移行を無停止で完遂
- 決済手数料率の改善により、年間数千万円規模のコスト削減を実現
